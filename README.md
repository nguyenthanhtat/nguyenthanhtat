### What I work on

- **Full-stack web.** TypeScript across the stack: Next.js and React on the front, NestJS and Node.js services behind them, PostgreSQL or MongoDB underneath, shipped with Docker, Vercel and Cloudflare Workers.
- **Data engineering.** Google BigQuery in production: event pipelines, scheduled transforms, partitioning and clustering for cost, access control, and keeping the bill predictable.
- **AI developer tools.** Claude Code plugins, skills, hooks and agents, built with evals so they measurably improve answers instead of just adding prompts.

### How I like to work

- Measure before optimizing: dry runs, query plans and evals before opinions.
- Make the safe path the default: read-only first, reversible changes, explicit approval for anything destructive.
- Ship small and keep it documented, so the next person can run it without asking.
